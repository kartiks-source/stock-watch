# Plain copy: so a 5-year-old could follow it

## The test
Read each line out loud. If a child would ask "what does that mean?", rewrite it.

## Rules
1. **One idea per sentence. One idea per slide.** Max ~12 words a sentence.
2. **Small, everyday words.** "Ran out", not "stock-out episode". "Sold", not "net items sold". "How fast it sells", not "velocity" or "rate basis". "Money we missed", not "lost revenue attribution".
3. **Use the shop picture.** Products sit on a shelf. Empty shelf = nobody can buy. Every rule can be told with the shelf.
4. **Every number gets a story.** Not "₹74k lost" but "The Oakwood table was gone for 20 days. People would have bought about 14. That's about ₹74k we missed."
5. **Numbers people can hold.** Round: ₹74k, ₹4.8 lakh, 5 a week. Exact numbers go in notes, not on the slide.
6. **Say when.** Every number says its dates: "1–24 Nov", "last 30 days".
7. **Lead with the answer.** Title = the point ("Best sellers ran out. We missed ₹4.8 lakh."), not the topic ("Lost sales analysis").
8. **No jargon, no abbreviations** (no SKU on slides unless shown next to the name and picture; no "G26", "NR", "ROAS" without saying what it means).
9. **Show, don't list.** A picture of the shelf, a bar that empties, a calendar with red days beats a bullet list.
10. **Decimals only where they help**, always with the plain version next to it: "0.73 a day (about 5 a week)".
11. **Kind and clear about doubt.** "This one is a guess: it hardly ever sells." Not "low-confidence estimate".

## Swap list
| Instead of | Say |
|---|---|
| stock-out | ran out / empty shelf |
| in-stock rate / velocity | how fast it sells |
| lost revenue / lost sales | money we missed |
| counted (headline) | sure |
| estimate (low confidence) | a guess |
| not restocked 30+ d | nobody refilled it for a month: refill or drop? |
| window / period | these days (1–24 Nov) |
| allocation / committed / on hand | (leave out, or: "the website count") |
| SKU | product code (only next to name + picture) |
